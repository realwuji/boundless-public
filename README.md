# Boundless

Your reading, on your terms.

Boundless is a reader for manga, manhwa, webtoons, and novels. It is a reader for content you bring yourself: it hosts nothing of its own, runs entirely on your device, and never requires an account. Bring your own files, connect a self-hosted library such as Komga, or add sources through the app's extension system, and read everything in one consistent, customizable place.

This repository holds the public documentation and the Android release builds. The app's source code is not published here.

## Download

Android builds are published on the [Releases](../../releases) page of this repository. Each release includes a signed APK and its release notes.

Requirements: Android 7.0 or newer.

The iOS version is distributed through the App Store. See [boundless.moe](https://boundless.moe) for current availability on every platform.

## Installing on Android

1. Download the `.apk` file from the latest release.
2. Open the downloaded file. If Android asks, allow installing apps from your browser or file manager (this is a one-time permission, and Android will show exactly which app is asking).
3. Tap Install, then open Boundless.

Updating works the same way: install the newer APK over the existing one. Your library, settings, and reading progress stay in place, since every release is signed with the same key.

If Android refuses to install an update, the most common cause is a copy that was not downloaded from this page. Uninstalling and reinstalling from here resolves it, after which a backup can be restored from Settings.
